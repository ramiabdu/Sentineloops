# Roadmap

## Current Status

SentinelOps is at a production-style MVP baseline. It has the core API, scanner contracts, persistence, worker loop, dashboard UI, CI, docs, screenshots, and deployment-ready configuration.

## Near Term

- Deploy public demo on Railway and Vercel
- Add real identity provider integration
- Add old access key scanner
- Add missing storage encryption scanner
- Add audit log model and APIs
- Add alert routing for high-severity findings

## Medium Term

- Add pagination to findings and accounts APIs
- Add organization and tenant boundaries
- Add cloud credential onboarding flow
- Add scanner execution telemetry
- Add production observability dashboards

## Longer Term

- Add multi-cloud scanner packs
- Add policy-as-code rules
- Add remediation workflow
- Add benchmark mapping such as CIS or internal policy controls
- Add deployment modules for a real production environment
